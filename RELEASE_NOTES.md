# TIT Q v0.5.0

Free 10-band dynamic equaliser with minimum, linear and mixed phase.

## Download
Download the zip for your system from the **Assets** list below:
- `TITQ-Windows-VST3.zip`: Windows (VST3).
- `TITQ-macOS-VST3.zip` and `TITQ-macOS-AU.zip`: macOS (VST3 and AU). One universal build for Apple Silicon and Intel.
- `TITQ-source.zip`: source code.

Unzip it and copy `TIT Q.vst3` to your VST3 folder (Windows: `C:\Program Files\Common Files\VST3`; macOS: `/Library/Audio/Plug-Ins/VST3`, AU: `/Library/Audio/Plug-Ins/Components`), then rescan plugins in your DAW.
Unsigned macOS builds: in Terminal run `xattr -cr "TIT Q.vst3"` (or `.component`).

## What's in it
- 10 bands with per-band dynamics, sidechain and character bands (SLTIT, TIT 250, AP TIT, TIT SKY, BOOBTEC).
- Phase: minimum, linear or mixed (minimum below ~500 Hz, linear above).
- BOOBTEC with a four-position frequency selector (20/30/60/100).
- High-accuracy engine near Nyquist, sample-by-sample coefficient interpolation.

Free and open source (AGPLv3). No registration.
